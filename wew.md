## Задание 1: Реализация полной температурной компенсации MS5611

### Теоретическое введение

MS5611 — это датчик давления и температуры, используемый в барометрах для дронов. Для получения точных показаний необходима температурная компенсация с использованием калибровочных коэффициентов, хранящихся в PROM датчика.

### Реализация алгоритма

```python
# ms5611_compensation.py
import numpy as np
import matplotlib.pyplot as plt

def ms5611_calculate(raw_pressure, raw_temperature, C1, C2, C3, C4, C5, C6):
    """
    Расчёт давления и температуры с компенсацией MS5611
    """
    # Разница температуры относительно опорной
    dT = raw_temperature - C5 * 2**8
    
    # Фактическая температура (°C × 100)
    TEMP = 2000 + dT * C6 / 2**23
    
    # Вторичная компенсация для низких температур
    if TEMP < 2000:
        T2 = (dT * dT) / 2**31
        TEMP = TEMP - T2
    
    # Компенсация смещения и чувствительности
    OFF  = C2 * 2**16 + (C4 * dT) / 2**7
    SENS = C1 * 2**15 + (C3 * dT) / 2**8
    
    # Вторичная компенсация для низких температур
    if TEMP < 2000:
        OFF  = OFF - (T2 * 5) / 2**1
        SENS = SENS - (T2 * 3) / 2**1
    
    # Скомпенсированное давление (мбар × 100)
    P = (raw_pressure * SENS / 2**21 - OFF) / 2**15
    
    return TEMP / 100.0, P / 100.0  # °C и мбар

def calculate_heights(pressures, P0=1013.25):
    """Расчёт высоты двумя методами"""
    h_linear = (P0 - pressures) * 0.0842  # линейное приближение, м
    h_exact = 44330 * (1 - (pressures / P0) ** 0.1903)  # барометрическая формула, м
    return h_linear, h_exact
```

## Задание 2: Моделирование IIR-фильтра и выбор коэффициента α

### Теоретическая часть
```python
Фильтр нижних частот первого порядка (экспоненциальное сглаживание):

y[n] = α·x[n] + (1-α)·y[n-1]

где:

α — коэффициент фильтра (0 < α < 1)

Постоянная времени: τ = dt·(1-α)/α

Частота среза: f_c = α/(2π·dt·(1-α))

Реализация IIR фильтра
python
def iir_filter(data, alpha):
    """IIR фильтр первого порядка"""
    filtered = np.zeros_like(data)
    filtered[0] = data[0]
    for i in range(1, len(data)):
        filtered[i] = alpha * data[i] + (1 - alpha) * filtered[i-1]
    return filtered

def calculate_rmse(filtered, true):
    """Среднеквадратичная ошибка"""
    return np.sqrt(np.mean((filtered - true)**2))

Ответы на вопросы
Вопрос 1: Как выбрать α по заданной постоянной времени τ?

Формула: α = dt / (τ + dt)

Пример: при τ = 0.1 с и dt = 0.012 с → α = 0.012 / (0.1 + 0.012) = 0.107

Вопрос 2: Почему α = 0.3 не всегда хороший выбор?

Основные причины:

Постоянная времени: α=0.3 даёт τ = 0.028 с, что слишком мало для эффективного подавления низкочастотных шумов

Компромисс шум-задержка:

Малые α (<0.1): хорошее шумоподавление, но большая задержка (0.1-0.2 с)

Средние α (0.2-0.4): баланс для типичных полётов

Большие α (>0.7): малая задержка, но плохое шумоподавление

Зависимость от динамики:

Висение: нужно α ≈ 0.05-0.1 (сильное сглаживание)

Медленный полёт: α ≈ 0.2-0.3 (компромисс)

Активные манёвры: α ≈ 0.5-0.7 (малая задержка)

Выводы по заданию 2
Оптимальный α для статики: 0.05-0.1 (RMSE минимален)

Оптимальный α для динамики: 0.3-0.5 (компромисс)

Универсального α не существует — необходима адаптация

Рекомендация: использовать α = 0.15-0.25 для большинства применений
```

```python
Зачем нужна вертикальная скорость?
Вертикальная скорость используется как D-составляющая (производная) в ПИД-регуляторе высоты:

Управление = Kp·e + Ki·∫e·dt + Kd·(de/dt)

Функции D-компоненты:

Демпфирование — уменьшает колебания вокруг заданной высоты

Упреждение — позволяет提前 реагировать на изменение высоты

Стабилизация — предотвращает "проскакивание" целевой высоты
```

## Задание 4: Моделирование слияния барометра и акселерометра

```python
Постановка задачи
Барометр даёт абсолютную высоту, но с шумом. Вертикальный акселерометр даёт ускорение (дважды интегрируя — высоту), но накапливает дрейф. Их можно объединить комплементарным фильтром.

Реализация комплементарного фильтра
python
def complementary_filter(h_baro, a_meas, dt, alpha):
    """Комплементарный фильтр для слияния барометра и акселерометра"""
    h_comp = np.zeros_like(h_baro)
    v_est = 0
    
    h_comp[0] = h_baro[0]
    
    for i in range(1, len(h_baro)):
        # Предсказание по акселерометру
        v_est = v_est + a_meas[i-1] * dt
        h_pred = h_comp[i-1] + v_est * dt + 0.5 * a_meas[i-1] * dt**2
        
        # Обновление по барометру
        h_comp[i] = alpha * h_pred + (1 - alpha) * h_baro[i]
    
    return h_comp
```
